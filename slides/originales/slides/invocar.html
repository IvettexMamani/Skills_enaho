Hay dos caminos. Por defecto, Claude decide solo cuándo usarla según la descripción. O la llaman ustedes escribiendo barra y el nombre, y pueden pasarle argumentos, que dentro del archivo se leen con $ARGUMENTS o con $0, $1. Los comandos de barra que quizá conocen ya se fusionaron con las skills: un archivo en .claude/commands sigue funcionando, pero lo nuevo se hace como skill. Para ver cuáles tienen, escriban /skills o pregúntenle a Claude qué skills hay. Si editan SKILL.md, Claude Code toma el cambio sin reiniciar.
