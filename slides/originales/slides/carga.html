Carga progresiva

Claude lee la skill en tres niveles, no toda de golpe

1 · Siempre

name y description

Unos 100 tokens por skill, desde que abres Claude Code

2 · Al activarse

El cuerpo de SKILL.md

Menos de 5 mil tokens, solo cuando la tarea lo pide

3 · Si hace falta

Referencias y scripts

Nada hasta que se usan. Del script solo entra lo que imprime

Por eso pueden tener decenas de skills instaladas sin llenar el contexto.

Este es el concepto técnico más importante. Claude no lee todas las skills al inicio: solo ve el nombre y la descripción de cada una, unos cien tokens. Cuando un pedido coincide con una descripción, carga el cuerpo de esa skill. Y los archivos de apoyo los abre solo si los necesita. Con los scripts es aún mejor: los ejecuta, y al contexto entra solo la salida, no las cien líneas de pandas. Eso hace que una skill sea más barata y más confiable que pegar un prompt larguísimo.
