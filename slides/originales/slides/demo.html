# Limpiar la ENAHO
1. Si faltan los zip en datos/, pide al usuario bajarlos del INEI (código 966 = 2024).
2. Corre exactamente: uv run ${CLAUDE_SKILL_DIR}/scripts/limpiar.py --anio $0
3. Lee salidas/validacion.txt. Si la pobreza difiere del INEI en más de 0.1 puntos, detente.
4. Responde con salidas/personas_$0.parquet; toda cifra va ponderada con facpob07.
5. Antes de usar una variable que no está en la base, lee reference.md.

Así se ve la skill terminada. Noten tres cosas. La description dice qué hace y cuándo, con las palabras ENAHO, INEI, pobreza y región. El paso 2 no deja libertad: corre exactamente el script; CLAUDE_SKILL_DIR es la carpeta de la skill y $0 es el año que le pasan con /limpiando-enaho 2024. Y el paso 3 obliga a Claude a revisar la validación antes de responder: si la pobreza no cuadra, se detiene en vez de inventar.
