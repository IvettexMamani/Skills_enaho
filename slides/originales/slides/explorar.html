Estrellas al 31 de octubre de 2026. Cada nombre abre el repositorio; los comandos de instalación están en su README.

Estos son los repositorios que les recomiendo explorar durante el proyecto o en casa; cada nombre es un link. Los dos de Anthropic son la referencia: anthropics/skills tiene las skills de documentos y skill-creator, que es una skill para crear skills; knowledge-work-plugins tiene el plugin data, con validate-data, que les sirve de inspiración para hoy. K-Dense tiene 177 skills científicas, varias de estadística y ciencia de datos. Hugging Face tiene las suyas para datasets y entrenamiento. Superpowers es el más popular de forma de trabajar. Y las dos listas awesome sirven para buscar por tema. Para instalar las de Anthropic en Claude Code basta con agregar el repositorio como marketplace y luego instalar el plugin. Las de K-Dense se instalan con npx skills add o con gh skill install, según su README.
