Antes de instalar, lean el SKILL.md y sus scripts. Una skill ejecuta código en su máquina. La documentación recomienda usar solo las propias o las de Anthropic, y las estrellas no bastan: hay repos de 2026 con cientos de miles que no cuadran.

Para que vean que esto ya es un ecosistema. Hay skills para documentos, que son las oficiales de Anthropic para Excel, Word, PowerPoint y PDF. Hay de datos y estadística, que son las que más nos interesan: el plugin data de Anthropic trae explore-data y validate-data, que es casi lo que harán hoy. Hay skills de forma de trabajar, como depurar de forma sistemática o escribir un plan antes de programar. De diseño, de plataformas como Hugging Face o la API de Claude, y skills para crear skills. Una advertencia seria: una skill puede traer scripts que se ejecutan en su computadora. Léanla antes de instalarla. Y no se guíen por las estrellas: en GitHub hay repositorios creados este año con más estrellas que el de Anthropic, y eso no es creíble.
