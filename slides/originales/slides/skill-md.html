# Limpiar la ENAHO
1. Corre scripts/limpiar.py
2. Revisa validacion.txt
3. Para otras variables, lee reference.md

name

Minúsculas, números y guiones; hasta 64 caracteres. Será el comando /limpiando-enaho

description

Qué hace y cuándo usarla. Es lo único que Claude lee para decidir si la activa

El cuerpo

Pasos en Markdown; menos de 500 líneas

El archivo empieza con un bloque YAML entre tres guiones. En Claude Code todos los campos son opcionales, pero description es la que importa: si falta o es vaga, Claude nunca sabrá cuándo usarla. El name, por defecto, es el nombre de la carpeta. La documentación recomienda nombres en gerundio, como limpiando-enaho, y prohíbe usar las palabras anthropic o claude. El cuerpo son instrucciones normales; la recomendación oficial es mantenerlo bajo 500 líneas y mover el detalle a otros archivos.
